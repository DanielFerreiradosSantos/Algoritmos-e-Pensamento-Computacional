# Algoritmos e Pensamento Computacional

Este repositório foi criado para publicar e organizar meus trabalhos, atividades e projetos desenvolvidos durante a disciplina de **Algoritmos e Pensamento Computacional** da faculdade.

A ideia é utilizar este espaço para guardar os exercícios realizados durante as aulas e acompanhar minha evolução no aprendizado de programação.

---

## 📚 Sobre a disciplina

A disciplina aborda conceitos relacionados a:

- Lógica de programação
- Algoritmos
- Pensamento computacional
- Resolução de problemas
- Estruturas de controle
- Variáveis e tipos de dados
- Funções
- Linguagem C
- Entre outros conteúdos estudados durante o semestre
