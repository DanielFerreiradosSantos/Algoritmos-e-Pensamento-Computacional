Fala, pessoal! Beleza? 👋 

Este repositório foi criado para registrar meu aprendizado na faculdade na matéria de **Algoritmos e Pensamento Computacional**.

---

## 📌 Sobre o Projeto

No começo das aulas, a gente começou aprendendo a estruturar a lógica e a criar **fluxogramas no Flowgorithm**. Depois que a lógica ficou redondinha no papel/fluxograma, fizemos a transição para o código em **Linguagem C**.

Neste repositório você vai encontrar:
1. **O Fluxograma no Flowgorithm**: A lógica visual de como a calculadora funciona passo a passo.
2. **O Código em C**: O programa completo e funcional implementando a calculadora científica no terminal.

---

## 🚀 Funcionalidades da Calculadora

A calculadora conta com **20 operações disponíveis**:

### 🔹 Operações Básicas / Binárias (Pede 2 números: A e B)
1. **Soma** (`A + B`)
2. **Subtração** (`A - B`)
3. **Multiplicação** (`A * B`)
4. **Divisão** (`A / B` — com trava pra não dividir por zero!)
5. **Potência** ($A^B$)
6. **Módulo** (Resto da divisão)

### 🔸 Operações Avançadas / Unárias (Pede apenas 1 número: A)
7. **Raiz Quadrada**
8. **Seno**
9. **Cosseno**
10. **Tangente**
11. **Arco Seno (Asin)**
12. **Arco Cosseno (Acos)**
13. **Arco Tangente (Atan)**
14. **Logaritmo na Base 10**
15. **Logaritmo Natural (Ln)**
16. **Exponencial** ($e^A$)
17. **Valor Absoluto (Abs)**
18. **Parte Inteira (Int)**
19. **Função Sinal** (Retorna `1`, `-1` ou `0`)
20. **Fatorial** ($A!$)
