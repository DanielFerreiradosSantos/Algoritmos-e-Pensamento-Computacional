# Algoritmos e Pensamento Computacional

Este repositório foi criado para guardar atividades e projetos desenvolvidos durante a disciplina de **Algoritmos e Pensamento Computacional**.

O objetivo é colocar em prática os conteúdos aprendidos durante as aulas, principalmente lógica de programação e a linguagem C.

## 📚 Conteúdos do repositório

### 🧮 Calculadora Científica em C

Arquivo:

`calculadora cientifica em c`

Este projeto é uma calculadora científica desenvolvida em linguagem C.

A calculadora possui várias operações matemáticas, como:

- Soma
- Subtração
- Multiplicação
- Divisão
- Potência
- Módulo
- Raiz quadrada
- Seno
- Cosseno
- Tangente
- Arco seno
- Arco cosseno
- Arco tangente
- Logaritmo base 10
- Logaritmo natural
- Exponencial
- Valor absoluto
- Conversão para inteiro
- Sinal do número
- Fatorial

O projeto foi feito para praticar conceitos básicos de programação em C, como:

- Variáveis
- Tipos de dados
- Operadores
- `if` e `else`
- `while`
- `for`
- Funções
- Entrada de dados
- Saída de dados
- Strings
- Conversão de tipos
- Biblioteca matemática

## 📊 Fluxograma da Calculadora Científica

Arquivo:

`fluxograma da calculadora cientifica`

Este arquivo apresenta o **fluxograma da calculadora científica**.

O fluxograma serve para representar visualmente a lógica utilizada no programa.

Ele mostra de forma simples o caminho que o programa segue:

1. Início
2. Mostrar o menu
3. Escolher uma operação
4. Digitar os valores necessários
5. Realizar o cálculo
6. Mostrar o resultado
7. Voltar para o menu
8. Escolher `0` para sair
9. Fim
